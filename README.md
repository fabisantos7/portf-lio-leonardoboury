# Leonardo Boury — Dev.Portfolio

Portfólio pessoal de Leonardo Boury, desenvolvedor web. Apresenta projetos,
habilidades e formulário de contato. Construído com Next.js 16 (App Router),
React 19, TypeScript, Tailwind CSS 4, shadcn/ui, Framer Motion e Prisma.

## ✨ Seções

- **Sobre** — bio, foto, habilidades (com barras de progresso) e estatísticas.
- **Projetos** — cards com screenshot, descrição, tecnologias e link ao vivo.
- **Contato** — formulário que salva mensagens (SQLite via Prisma).

## 🚀 Deploy

Veja o **[README-VERCEL.md](./README-VERCEL.md)** para o passo a passo
completo de deploy no GitHub + Vercel (inclui o script `SUBIR-PARA-GITHUB`
que envia o projeto inteiro, pastas incluídas).

## 💻 Desenvolvimento local

```bash
npm install
npm run dev      # http://localhost:3000
```
